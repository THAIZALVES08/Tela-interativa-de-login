# Tela-interativa-de-login
https://thaizalves08.github.io/Tela-interativa-de-login/

 Desenvolvimento de uma Tela Interativa de Login

1. HTML – Estrutura da página
Criação da estrutura da tela de login
Criação dos formulários de login e cadastro.
Adição de campos para nome, usuário, e-mail e senha.
Criação dos botões Sign In e Sign Up.
Adição de áreas para apresentar mensagens ao usuário.

2. CSS – Personalização visual
Definição das cores de fundo e dos formulários.
Personalização dos botões, campos de entrada e textos.
Aplicação de bordas arredondadas e sombras.
Centralização dos elementos na página.
Criação de efeitos ao passar o mouse sobre os botões.
Adaptação da interface para diferentes tamanhos de tela.

3. Animação dos painéis
Implementação do efeito de deslizamento entre login e cadastro.
Utilização de transform para movimentar os painéis.
Utilização de transition para criar movimentos suaves.
Alternância entre os formulários por meio dos botões Sign In e Sign Up.

4. JavaScript – Interatividade
Utilização de variáveis para armazenar os dados digitados.
Utilização de getElementById() para acessar elementos HTML.
Utilização de addEventListener() para identificar cliques e envios de formulários.
Utilização de classList.add() e classList.remove() para controlar a animação.
Aplicação de estruturas condicionais if, else if e else.

5. Validação do login
Definição das credenciais de acesso: usuário aluno e senha 1234.
Verificação de campos vazios.
Verificação de usuário e senha corretos.
Exibição de mensagens de sucesso ou erro.
Desenvolvimento de uma validação demonstrativa para o formulário de cadastro.

6. Personalização do fundo
Escolha de uma imagem para personalizar o fundo da página.
Utilização de background-image, background-size e background-position para configurar a imagem.

7. Organização do projeto
Separação do código em três arquivos: login.html, style.css e script.js.
Organização e identificação das principais partes do código por meio de comentários.

8. Testes previstos
Testar login com usuário e senha corretos.
Testar usuário incorreto.
Testar senha incorreta.
Testar campos vazios.
Testar o preenchimento parcial.
Testar a animação de alternância entre login e cadastro.
